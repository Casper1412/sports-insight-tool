# Interactive Sports Analytics & Match-Tracking Tool

An interactive web application built with Python and Streamlit designed for live match tracking, spatial event visualization, and player intelligence.

## 🚀 Features
- **Live Match & Lineup Management:** Track scores, substitutions, and rule-based lineup validation.
- **Spatial Event Mapping:** Interactive shot-mapping and density heatmaps using spatial coordinates.
- **AI-Assisted Development:** Built using modern iterative workflows with ChatGPT Plus.
- **Reporting & Exports:** Data persistence via SQLite with dynamic Excel and PDF report generation.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Data & Visualization:** Pandas, Pillow, ReportLab, OpenPyXL
- **Database:** SQLite
- **AI Workflow:** ChatGPT Plus (AI-assisted coding)
